# UNIQUE ALL IN ONE

Crystal & jewelry store website. The app lives in [`website/`](./website).

```bash
cd website
npm install
npm run seed
npm run dev
```

- Storefront: http://localhost:3000  
- Admin: http://localhost:3000/admin (`admin` / `unique2026`)  
- Instagram: https://www.instagram.com/unique.all.in.one/
